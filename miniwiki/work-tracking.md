# Work tracking

This repository has no Beads database and no issue tracker for this handoff.
Continuity is maintained in this miniwiki only. The publication workflow is:

1. scrub and test the public-facing change set;
2. reconstruct the authorized subset from `origin/main`;
3. validate, review, and resolve findings;
4. publish directly to the upstream public repository;
5. record the merge evidence and retained private scope.

The workshop fleet, managed Omnigent host integration, and unrepaired findings
remain private until separately reviewed and authorized.
